# AGENTS — usage-dashboard

Правила для агентов, работающих с этим репозиторием.

## Запуск

```bash
python3 server.py                 # http://127.0.0.1:8787
python3 server.py --port 9000
python3 server.py --demo          # вымышленные данные, ключи не читаются
python3 server.py --demo problems # то же плюс карточки с ошибками
```

Зависимостей нет — только стандартная библиотека Python 3.11+.

## Структура

- `server.py` — HTTP-сервер (`/`, `/api/usage`, `/api/health`), кэш 25 с.
- `providers.py` — адаптеры сервисов, нормализация в карточку, `humanize_error`.
- `config.json` — включённые провайдеры и `custom`-блок для новых эндпоинтов.
- `secrets.env` — токены, `chmod 600`, в `.gitignore`.
- `web/index.html` — вся страница (CSS + JS без сборки).

## Правила

- Токены не логировать и не отдавать в браузер — только цифры и тексты ошибок.
- Новый провайдер: функция `fetch_<id>` → `BUILTIN` + `ORDER` → флаг в `config.json`.
- Ошибку всегда переводить в действие («выпусти новый ключ», «войди заново»).
- `--demo` показывает только выдуманные цифры и не обращается к ключам — так снимаются
  скриншоты для README, реальные данные в кадр не попадают.
- Проверка: `curl -s "http://127.0.0.1:8787/api/usage?force=1"` — все карточки должны
  иметь осмысленный `status`.
